# 私记 · 界面文案规范（工具腔）

> 本文件是界面文案的唯一依据。格式：**现文案 → 新文案**。未列出的字符串按第 0 节规则处理。
> 目标：坦诚、准确、短。像一个可靠的工具，而不是一本会说话的日记。

## 0. 规则

### 0.1 语气
- 直接说功能和结果，不修辞、不比喻、不安慰、不鼓励、不卖萌。
- 删除一切不带信息的句子（气氛句、口号、"慢慢来""不用勉强"之类）。
- 不用 emoji、颜文字、感叹号。
- 按钮、标签、状态、toast、占位符：**不加句末标点**。
- 说明文字、警告：完整句子，句号结尾。
- 技术错误照实说清原因和下一步，不要卖关子。

### 0.2 术语表（全应用统一）

| 概念 | 统一说法 | 不再使用 |
|---|---|---|
| 应用 | 私记 | 手记、这本手记、本地空间、保险库 |
| 本机全部数据 | 本机数据 | 手记、保险库 |
| 一次拍照记录 | 记录（量词：条） | 一笔、一页、打卡、次记录 |
| 照片 | 照片（量词：张） | — |
| 佩戴时间段 | 佩戴时段 / 时段（量词：个） | 一程、这段 |
| 佩戴中的中断 | 暂停 | 小憩、清洁小憩 |
| 锁上应用 | 锁定 | 合上、收起 |
| 打开应用 | 解锁 | 打开手记、开锁、翻开 |
| 解锁用的密码 | 密码 | 主密码 |
| 备份文件的密码 | 备份密码 | — |
| 快速解锁的期限 | 有效期 | 窗口 |
| 轮盘功能 | 命运轮盘（功能名） | — |
| 轮盘的一次抽取 | 结果（动词：转） | 判定、命运判定 |
| 每天限一次的轮盘方式 | 每日一次 | 每日仪式、仪式 |
| 不限次数的轮盘方式 | 不限次数 | 自由模式、自由沙盒 |
| 匿名分享图片 | 匿名分享图 | 小结、战报 |
| 删除 | 删除 | 删去、删掉、拿掉 |
| 编辑 | 编辑 | 改一改 |
| 保存 | 保存 | 收进今天、记下、存进 |

### 0.3 移除的元素
1. 页头品牌副题 `只写给自己`。
2. 页脚 `私记 · 只在这台设备上`（整个 `.page-footer`）。
3. 首页计时上方的气氛句 `这一程，已经` / `按自己的节奏来`：佩戴中改为 `本次时长`，未佩戴时不显示。
4. 首页轮盘徽标里的 `🎲`。
5. 首页轮盘入口的 `命` 字印章、统计页分享入口的 `简` 字印章：改用 lucide 图标（`Dices`、`Share2`），保留原容器样式。
6. 所有 toast 的句号。
